# Licensing: Apache 2.0

> Enterprise-friendly, mandatory attribution, patent protection.

---

## Decision

**Apache License 2.0** for all code in the repository.

---

## Why Apache 2.0

| Option | Rejected because |
|--------|-----------------|
| **MIT** | No attribution requirement. Forks remove Kapi branding. |
| **GPL** | Enterprise legal teams block it. Scares PMs. |
| **CC BY 4.0** | Explicitly not recommended for software. Creates legal ambiguity. |
| **AGPL** | Even more restrictive than GPL. Enterprise non-starter. |
| **Apache 2.0** ✅ | Enterprise-friendly + mandatory attribution + patent protection |

---

## What Apache 2.0 Gets Us

1. **Mandatory NOTICE file** — Every derivative must keep our attribution
2. **Enterprise-friendly** — Legal teams approve Apache 2.0 without friction
3. **Patent grant** — Contributors grant patent rights (protects users)
4. **Modification tracking** — Modified files must state changes
5. **No copyleft** — Companies can use in proprietary products
