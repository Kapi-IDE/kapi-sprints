# ADR: Use Next.js App Router for all routes

## Context

Evaluating Next.js Pages Router vs App Router for the project. App Router enables React Server Components, streaming, and better data fetching patterns. Pages Router is more mature and has wider community examples.

## Decision

Use App Router. RSC reduces client JS bundle. Streaming enables progressive loading. The project will be greenfield so Pages Router compatibility is not a concern.
