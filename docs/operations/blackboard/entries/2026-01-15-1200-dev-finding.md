# Auth token storage: localStorage is XSS-vulnerable

## Finding

The initial implementation stores the JWT in `localStorage`. This is vulnerable to XSS attacks — any injected script can steal the token.

## Recommendation

Switch to `httpOnly` cookies before any production deploy. The server sets the cookie; JavaScript cannot read it. Implement CSRF protection (SameSite=Strict or double-submit cookie pattern).

## Impact

Blocks T04 (user auth) going to production. Fine for local dev/staging.
