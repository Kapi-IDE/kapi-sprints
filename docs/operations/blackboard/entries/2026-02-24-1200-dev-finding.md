# Finding: Overview should be the default view, not a Blackboard tab

## Finding

Early version had a "Blackboard" tab in the sidebar. Removed it — the Overview panel already shows all the blackboard intel (blockers, decisions, findings, agent status) in a compact command-center layout. Having a separate Blackboard tab created redundancy and made the Overview feel incomplete.

## Recommendation

Keep Overview as the default landing. Each Overview card links directly to the source `.md` file for full detail. The Blackboard tab is unnecessary.

## Impact

Implemented. Blackboard tab removed in v1. Overview is now the canonical blackboard view.
