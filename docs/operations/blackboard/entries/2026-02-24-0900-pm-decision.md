# License: Apache 2.0

## Context

kapi-sprints is intended as an open-source tool for Claude Code teams. Needed to pick a license before first public commit.

## Decision

Apache 2.0. More permissive than GPL (companies can use without open-sourcing their sprints). Includes patent grant, which MIT lacks. Better for enterprise adoption than AGPL.

## Status

Accepted feb 24. LICENSE file committed.
