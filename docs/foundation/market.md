# Market & Users

## Ideal Customer Profile

Technical PMs and dev leads at teams of 2-10 using Claude Code (or similar AI coding agents) for daily development. They've hit the wall: agents forget context, multiple terminals conflict, and there's no visibility into what's happening across the team. Typically at startups or innovation teams within larger companies.

## Current Alternatives

| Alternative | Why it fails |
|------------|-------------|
| No tooling (just run terminals) | No coordination, no persistence, no audit trail |
| Linear/Jira | Built for human project management, not AI agent coordination. No blackboard, no file-based workflow. |
| Custom CLAUDE.md instructions | Helps one terminal, doesn't coordinate across multiple. No dashboard. |
| Cursor/Windsurf built-in features | IDE-specific, no cross-terminal coordination, no sprint structure |

## Willingness to Pay

Free (OSS). The product is a brand vehicle for Kapi AI. Value is measured in GitHub stars, npm installs, and PMs who experience the blackboard pattern and then explore getkapi.com.

## Market Size

Claude Code has hundreds of thousands of active users (as of early 2026). The subset running multi-terminal workflows or managing AI agents in teams is the target — estimated 10-50K developers who would benefit from structured sprint tooling.
